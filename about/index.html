飞行手册 +

借力. 按住画面或引力键, 抓住亮圈内的星球. 松开沿虚线方向飞出. 再按一次可以抓住另一颗星球, 紧急改道.

冒险. 穿过金色信号环得分, 连续换轨提高倍率. 红色陨石会撞毁飞船, 身后的黑洞会不断追赶. 停留太久就会被吞没.

救场. 每局可以倒带一次, 坠毁后仍有机会回到两秒前. 连续到达新星球会获得护盾、引力强化或收集分身.

再来. 坚持 75 秒完成逃离. 重试保留当前航线, 刷新页面会开启新航线. 同航线的最佳飞行会留下虚线幽灵, 它不会发生碰撞.

空格键控制引力, R 倒带, P 或 Esc 暂停. 切到其他窗口或离开游戏区域会自动暂停. 柔和画面关闭闪烁、拖尾和镜头缓动, 保留飞行操作.

站点含义

0x53C4

ZiWei Archive 是一个个人信号收集器, 用来保存文章, 碎片和还没有被整理完的想法.

名字是一个坐标, 不是结论. 归档会持续变化, 但每一次写入都会留下痕迹.

视觉协议

0x7FAF

黑白像素, 抖动颗粒和终端式信息面板组成页面的基础语法.

少量绿色只表示系统仍在运行, 其余空间留给文字和下一条信号.

搭建过程

0xF15E

页面使用原生 HTML, CSS 和 Canvas 构建, 不依赖运行时服务, 打开即可读取.

静态结构让内容可以被长期保存, 也让每一处视觉细节都保持可控.
